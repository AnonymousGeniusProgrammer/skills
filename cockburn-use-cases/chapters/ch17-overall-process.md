# Chapter 17: Use Cases in the Overall Process

## Core Idea

Use cases support discovery, estimation, prioritization, design, testing, and communication; their detail should evolve with the development process.

## How to Apply

Use actor-goal lists for early scope and release conversation, briefs for estimation and shared understanding, detailed cases for high-risk behavior, and scenarios as inputs to acceptance tests and UI/design discussions.

## Key Takeaways

1. The same use case can support different lifecycle decisions at different precision levels.
2. Use cases link requirements work with design and testing rather than replacing either.
3. Keep feedback loops active as scenario exploration changes the model.
