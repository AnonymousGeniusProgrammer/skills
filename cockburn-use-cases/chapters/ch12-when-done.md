# Chapter 12: When Are We Done?

## Core Idea

Use-case completeness is fit for purpose, not maximal detail. Stop when intended readers can make the decisions or build and test the behavior with the chosen tolerance and ceremony.

## How to Apply

Review scope, level, primary actor, stakeholder interests, preconditions, guarantees, MSS, extensions, variations, and linked information. Increase detail only where uncertainty, risk, or consequence warrants it.

## Key Takeaways

1. “Done” depends on purpose and project tolerance.
2. Unreadable completeness is not useful completeness.
3. Guarantees and extension outcomes make review concrete.
