# Chapter 16: The Missing Requirements

## Core Idea

Use cases cover behavioral requirements only. A complete specification also needs linked requirements for rules, data, interfaces, qualities, process, operations, and human context.

## How to Apply

Put behavior in scenarios; reference rather than duplicate business rules, data definitions, performance targets, security details, UI standards, and external interface formats. Keep these artifacts traceable from relevant use cases.

## Key Takeaways

1. Do not force every requirement into a use case.
2. The use-case set can be a linking structure for disparate requirements.
3. Separate artifacts reduce prose clutter and ownership confusion.
