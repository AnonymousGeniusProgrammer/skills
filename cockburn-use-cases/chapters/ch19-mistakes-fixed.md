# Chapter 19: Mistakes Fixed

## Core Idea

Most use-case failures are repairable by rechecking scope, actor, goal level, stakeholder interests, and the separation of main flow from conditions.

## Review Moves

- If it reads like UI instruction, rewrite each step as an actor intention and result.
- If it is too large or too small, apply the coffee-break and how/why tests.
- If it misses obligations, run a stakeholder-interest audit.
- If it contains sprawling conditionals, retain the MSS and move branches to extensions.
- If it contains data rules or quality targets, link the relevant external requirement.

## Key Takeaways

1. Diagnose the model before rewriting prose.
2. The goal level and scope are common root causes.
3. Short feedback cycles keep corrective work cheap.
