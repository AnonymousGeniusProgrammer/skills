# Chapter 21: The Use Case Set

## Core Idea

The use-case set is the organized behavioral model of the system. Its value depends on coverage, navigability, stable scope, and useful relationships between goals.

## Set-Level Checklist

- Does every primary actor have an appropriately exhaustive goal list?
- Are outermost summary cases present where they provide context?
- Are goal levels consistently useful rather than uniformly detailed?
- Can stakeholders identify scope, priorities, releases, and missing work from the set?
- Are related non-behavioral requirements traceable from relevant use cases?

## Key Takeaways

1. Optimize the set before polishing individual cases.
2. Goal lists support prioritization, estimation, ownership, and release planning.
3. A hierarchy of summary, user-goal, and selective sub-use cases aids navigation.
