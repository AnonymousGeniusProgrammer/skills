# Chapter 13: Scaling Up to Many Use Cases

## Core Idea

Scale through a coherent use-case set: actor-goal lists, summary use cases, priorities, and controlled detail—not by expanding every possible subfunction.

## Frameworks Introduced

- **Use-case set as an ever-unfolding story**: summary use cases organize user-goal cases, which may selectively unfold into subfunctions.
- **Set-level organization**: use actor goals, scope artifacts, and briefs to coordinate teams and releases.

## Key Takeaways

1. A stable user-goal list is a management and communication asset.
2. Summary use cases provide navigable context.
3. Add detail only where it serves a reader or decision.
